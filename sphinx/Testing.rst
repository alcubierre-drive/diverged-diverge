Testing
=======

divERGe uses `ctest.h <https://github.com/alcubierre-drive/ctest>`_ for testing.
Running the tests can be achieved by a call to :c:func:`diverge_run_tests`, or
by running the ``divERGe`` executable.

.. _ctest: https://github.com/alcubierre-drive/ctest
