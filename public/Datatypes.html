XORSWAP_UNSAFE(a, b)
[source]

swap operands using the XOR-swap algorithm, fails if applied on the same element.

[source]

XORSWAP_PTR(a, b)
[source]

swap operands using the XOR-swap algorithm, but for pointers (C doesn’t allow ptr1 ^= ptr2, that’s why we need a second macro)
