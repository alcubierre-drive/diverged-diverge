Phonons

We include facilities to implment the flow equations (in static TU approximation) under the influence of non-interacting phonons coupled to the electronic system. Even though only the phonon hopping and electron-phonon vertices are required (see diverge_model_internals_tu_phonons()), it is recommended to build a diverge_model_t instance for the phonons as well—that way, the phonon model can easily be checked.

Creating the lattice-spring model for the phonon dispersion is very similar to creating tight-binding models for electrons. divERGe includes a function to make the phonon model comply with the acoustic sum rule; diverge_phonons_asr().

The electron-phonon coupling is given in real-space (similar to the file format in EPW).

struct ph_vertex_t
[source]

electron-phonon vertex structure in real space. Some member types are chosen in a specific way to yield a type that’s as large as rs_vertex_t. This equivalence is important and must not be violated!

The three-leg vertex is characterized by three quantum numbers. Two electronic ones (1,2) and one bosonic one (A). Its real-space version therefore reads

\(g^{1,2}_A \equiv g^{(\boldsymbol0,o_1,s_1),(\boldsymbol{R}_{12},o_2,s_2)}_{(O_A,\boldsymbol{R}_A)} \,.\)

In literature, \(g\) is commonly encountered in momentum space. This is equivalent to performing an FFT on both \(\boldsymbol{R}_{12}\) and \(\boldsymbol{R}_A\):

\(g^{(o_1,s_1),(o_2,s_2)}_{O_A}(\boldsymbol q, \boldsymbol k) = \sum_{\boldsymbol R_{12}, \boldsymbol R_A} e^{-i\boldsymbol q\cdot \boldsymbol R_A} e^{-i \boldsymbol k\cdot\boldsymbol R_{12}} g^{(\boldsymbol0,o_1,s_1),(\boldsymbol{R}_{12},o_2,s_2)}_{(O_A,\boldsymbol{R}_A)} \,.\)

To get comfortable with real-space electron-phonon coupling, you can have a look at the examples.

char mode
[source]

mode selection for the phononic ‘transfer’ vector. If mode == '0' use the lattice vector FFT (RA). Otherwise the phonon is situated at the floating point position RA_pos (in crystal coordinates; the real position is \(R_A^\mathrm{pos} \cdot L\) with \(L\) the lattice vector matrix) and an explicit floating point fourier transform (i.e. not an FFT) is performed for the respective component.

rs_hopping_t *diverge_phonons_asr(rs_hopping_t *ph_hop, index_t *n_ph_hop)
[source]

apply the acoustic sum rule (ASR) to a set of phonon hopping parameters. This function invalidates the pointer ph_hop, use as if realloc were called (i.e. use the returned pointer!).

Parameters:

  • ph_hop (rs_hopping_t*) – hopping parameter array (spring constants), must be allocated via calloc/malloc/realloc (or their divERGe wrappers) because we use realloc on this pointer internally!

  • n_ph_hop (index_t*) – number of hoppings, points to new number of hoppings on return.

Returns rs_hopping_t*:

hopping parameter array, reallocated.

complex128_t *diverge_phonons_get_g(diverge_model_t *m, int refined)
[source]

returns the electron-phonon coupling as an array (my_nk, n_spin, n_spin, n_orbff, nO), with my_nk the symmetry-reduced BZ (see TU backend) and nO the number of phonon modes. In case this array is written to the changes are applied to the RG flow (this is the actual buffer, not a copy). May return NULL in case phonon internals are not initialized.

if (refined), return the refined electron-phonon coupling buffer, size being (n_refine, n_spin, n_spin, n_orbff, nO). The size of refinement can be returned with diverge_phonons_get_refine().

double diverge_phonons_change_regulator(double eta)
[source]

Changes the phonon propagator regulator \(\eta\) for the \(iq_0 \to 0\) limit:

\[D_\nu(\boldsymbol{q}, iq_0) = \mathrm{Re}\bigg[ \frac{1}{(iq_0)^2 - i\eta - \omega_{\nu}(\boldsymbol{q})^2} \bigg]\]

This is highly relevant for the application of the theory to acoustic modes. The function returns the old value for \(\eta\). If qnan_isnan(eta) the regulator is left unchanged; this serves the purpose of allowing to look up the current value.

ph_vertex_t *diverge_phonons_asr_vertex(ph_vertex_t *vtx, index_t *n_vtx)
[source]

apply an acoustic sum rule to the electron phonon coupling vertices. assumes three dimensional phonon “orbitals”, i.e., (o,d) ordering of the OA index (with o=0…n_sites-1 and d=0..2). operates on all vertex elements irrespective of their ph_vertex_t.mode setting. Ensures that

\[\sum_{\boldsymbol{R}_A, o_A} g_{xy}(\boldsymbol{R}_A, (o_A, d_A)) = 0\]

with \(x,y\) electronic indices (orbital, spin, formfactor) and \(o_A, d_A\) the phononic sites/directions.

Parameters:

  • vtx (ph_vertex_t*) – vertex array, must be allocated via calloc/malloc/realloc (or their divERGe wrappers) because we use realloc on this pointer internally!

  • n_vtx (index_t*) – number of hoppings, points to new number of vertices on return.

Returns ph_vertex_t*:

vertex array, reallocated.

int diverge_phonons_asr_vertex_set_sorted_mode(int sorted)
[source]

change implementation behavior of diverge_phonons_asr_vertex() to an implementation that sorts all vertex elements and then looks at displacements/counts of unequal ‘formfactor’ components in order to sum them up and thus executes in parallel. should be faster for very large models, but slower for small models. returns previous mode (in order to save/restore state).

ph_vertex_t *diverge_phonons_read_elph(const char *wigner, const char *epmatwp, const double *masses, double maxrel, index_t *p_vtx_sz, int apply_asr)
[source]

read electron-phonon coupling from a wigner.fmt file wigner and an .epmatwp file epmatwp.

Parameters:

  • wigner (const char*) – wigner.fmt file name

  • epmatwp (const char*) – epmatwp file name

  • masses (const double*) – The atom masses (as provided by diverge_phonons_model_get_masses() given a model built with diverge_phonons_read_ifc(), array of shape n_orb) that must be provided.

  • maxrel (double) – relative maximum value cutoff (in real space). Let \(M\) be the maximum of the electron-phonon coupling and \(R\) this cutoff. Then all elements \(g_{Rx}^{R'ab}\) that fulfill \(|g_{Rx}^{R'ab}| < RM\) are discarded.

  • p_vtx_sz (index_t*) – length of the returned array.

  • apply_asr (int) – apply the vertex acoustic sum rule (cf. diverge_phonons_asr_vertex()).

Returns:

array of type ph_vertex_t with the real-space elph elements, shape (*p_vtx_sz,).
