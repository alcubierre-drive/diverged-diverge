FPLO¶

diverge_model_t *diverge_read_fplo(const char *fname)¶
[source]

read FPLO Hamiltonian files (+hamdata) into diverge_model_t objects. Only sets/reads the members listed below and leaves everything else untouched:

  • initializes the diverge_model_t via diverge_model_init()

  • sets the hopping parameters (diverge_model_t.hop)

  • sets the number of orbitals (diverge_model_t.n_orb)

  • sets the number of spins (diverge_model_t.n_spin)

  • sets the real space lattice (diverge_model_t.lattice) and positions (diverge_model_t.positions)

  • returns NULL on errors / if FPLO reader not compiled in

Note

This function is not compiled into the library by default. Enable compilation of the FPLO reader by passing the USE_FPLO_READER flag in the Compilation process (see Compilation DEFINES).
