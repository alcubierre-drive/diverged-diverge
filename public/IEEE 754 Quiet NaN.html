IEEE 754 Quiet NaN¶

Overloading double precision numbers can be quite useful for certain magic parameters or dual input. Hence, divERGe provides basic quiet NaN facilities listed below:

static inline int qnan_isnan(double qnan)¶
[source]

check whether a double holds a quiet NaN (same as fnan_isnan())

static inline double qnan_gen(uint32_t payload)¶
[source]

generate a quiet NaN that has a 32bit unsigned integer payload (see fnan_gen())

static inline uint32_t qnan_get(double qnan)¶
[source]

get the 32bit unsigned integer payload from a quiete NaN (see fnan_get())

static inline int fnan_isnan(double fnan)¶
[source]

check whether a double holds a quiet NaN (same as qnan_isnan())

static inline double fnan_gen(float payload)¶
[source]

generate a quiet NaN that has a 32bit floating point payload (see qnan_gen())

static inline float fnan_get(double fnan)¶
[source]

get the 32bit floating point payload from a quiete NaN (see qnan_get())
