Flow¶

divERGe does not include an automatic flow integrator. To achieve quasi-automatic integration, users are expected to

  • create a diverge_flow_step_t object (see Flow Step Object)

  • create a diverge_euler_t object (see Flow Integration)

  • wrap this in a do {} while() loop (see Flow Integration) until a stopping criterion is reached.

  • call postprocessing routines and save the output to disk (see Postprocessing and Output)
