Parameters:

  • model (diverge_model_t*) – the model with initialized common internals (diverge_model_internals_common()) but without specific ones (via diverge_model_internals_tu(), diverge_model_internals_patch(), diverge_model_internals_grid())

set the filling value

Parameters:

  • model (diverge_model_t*) – the model with initialized common internals (diverge_model_internals_common()) but without specific ones (via diverge_model_internals_tu(), diverge_model_internals_patch(), diverge_model_internals_grid())

  • E (double*) – energy array. if (E == NULL) the internal energy array is used and modified. Otherwise E is used and modified.
